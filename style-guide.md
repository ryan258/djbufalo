# DJ BUFALO — Brand Style Guide v1.0

**Baseline / September 2026**

## 1. Brand Core

| Element                       | Locked Baseline                                                                                                                                    |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Brand Name**                | DJ BUFALO                                                                                                                                          |
| **Positioning**               | A cult Buenos Aires electronic artist built around impeccable late-night taste, Argentine specificity, and a completely deadpan buffalo mythology. |
| **Core Tension**              | Underground credibility × absurdly committed buffalo character                                                                                     |
| **Primary Location**          | Buenos Aires, Argentina                                                                                                                            |
| **Cultural Anchor**           | Chacarita / Buenos Aires nightlife                                                                                                                 |
| **Representation**            | **MANZIA BOOKINGS**                                                                                                                                |
| **Primary Brand Feeling**     | “I found something.”                                                                                                                               |
| **Brand Traits**              | Deadpan / Cultured / Nocturnal                                                                                                                     |
| **Perceived Quality**         | Collectible, precise, restrained, culturally credible                                                                                              |
| **Primary Audience Position** | Underground electronic music audience with visual and cultural literacy                                                                            |

### Brand principle

**The music is serious. The buffalo is never explained.**

The humor comes from treating the entire Bufalo mythology as completely normal.

---

# 2. Brand Architecture

## DJ BUFALO

The artist is always the primary identity.

DJ Bufalo owns:

**Music / Sets / Releases / Artist imagery / Merchandise / Social presence / Website / Event communication**

## BUFALO

The mascot is the recurring character and mythology layer.

Bufalo is not a separate children's-style mascot brand. It exists inside the artist identity.

## MANZIA BOOKINGS

Manzia is the administrative and representation layer.

Correct usage:

`MANZIA BOOKINGS`
`FECHAS / CONTACTO`
`booking@djbufalo.com`

Manzia should never compete visually with DJ Bufalo.

### Hierarchy

**DJ BUFALO → dominant**
**Content / event / release → secondary**
**MANZIA BOOKINGS → administrative**

**MANADA RECORDS is not part of the current DJ Bufalo brand system.**

---

# 3. Visual Personality

The visual world is:

**Buenos Aires after midnight. Precise typography. Industrial darkness. Documentary photography. Tiny factual information. One inexplicable buffalo.**

It should feel closer to a limited-run record sleeve, archival club poster, or obscure cultural publication than conventional DJ marketing.

### Avoid

Generic EDM graphics, cyberpunk neon, brown-heavy vintage styling, black-and-gold luxury, cartoon mascots, meme aesthetics, influencer imagery, Argentine tourist clichés, unnecessary distortion, excessive grunge, and decorative “underground” effects.

---

# 4. Color System

| Role                   | Color             |       HEX | Usage                                     |
| ---------------------- | ----------------- | --------: | ----------------------------------------- |
| **Primary Background** | Obsidian          | `#0B0B0A` | Main canvases, website, posters           |
| **Primary Light**      | Bone              | `#F1EDE4` | Headlines, body, graphics                 |
| **Secondary Dark**     | Charcoal          | `#1A1917` | Panels, cards, separation                 |
| **Signature Accent**   | Bufalo Amber      | `#E8A33A` | Navigation, labels, key information       |
| **Unexpected Accent**  | Afterhours Violet | `#7668FF` | Handwritten intervention, rare highlights |

### Color ratio

**85% Neutral / 12% Amber / 3% Violet**

Amber identifies the brand.

Violet disrupts the brand.

Violet should therefore never become routine.

### Background rule

True white should rarely be used as a large surface. The brand lives primarily in dark environments.

---

# 5. Typography System

The system uses **three typographic voices**.

| Role          | Style                        | Function                                            |
| ------------- | ---------------------------- | --------------------------------------------------- |
| **Display**   | Heavy condensed grotesk      | DJ BUFALO, campaign statements, section headlines   |
| **Editorial** | Neutral contemporary grotesk | Biography, navigation, descriptive content          |
| **Utility**   | Monospaced                   | Dates, BPM, locations, codes, technical information |

### Current font baseline

**Display:** preserve the condensed grotesk character established in the current website. Exact production family should be locked when the implemented font files are audited.

**Editorial baseline:** Neue Montreal or a metrically comparable contemporary grotesk.

**Utility baseline:** IBM Plex Mono.

The visual **roles are locked even if exact production font families change**.

### Typography sizes — desktop baseline

| Element             |     Range |
| ------------------- | --------: |
| Hero H1             | 88–104 px |
| Section H2          |  42–52 px |
| Card headline       |  24–30 px |
| Body                |  15–17 px |
| Functional metadata |  11–13 px |
| Minimum microtype   |     10 px |

### Typographic behavior

Display type is blunt and compressed.

Body copy is calm and readable.

Mono type behaves like documentation.

Do not use decorative type simply to create personality. Personality comes from **hierarchy, copy, photography, and contrast**.

---

# 6. Logo / Wordmark

The primary verbal mark is:

## DJ BUFALO

Use the full name as the default artist identifier.

### Preferred treatment

Oversized condensed uppercase.

Bone on Obsidian is the primary configuration.

### Secondary mark

A simplified buffalo silhouette or physical mascot representation may operate as a recognizable symbol when the context already identifies DJ Bufalo.

### Do not

Stretch the wordmark, outline it unnecessarily, add gradients, add shadows, place it inside generic badges, combine it with novelty horns, or convert the buffalo into a cartoon logo.

---

# 7. Mascot System

The buffalo is one of the most important brand assets.

### Core rule

**Bufalo behaves as though his presence requires no explanation.**

### Physical character

The mascot should remain tactile, physical, plush, photographic and imperfect.

It should feel like an actual subject being documented.

### Preferred behaviors

At the booth, backstage, waiting, sitting, staring, travelling, standing in strange ordinary locations, appearing in documentation, or occupying spaces with complete seriousness.

### Expression

Neutral. Patient. Deadpan.

### Avoid

Sunglasses as a recurring gag, novelty costumes, dancing poses, exaggerated facial expression, speech bubbles, meme formats, cartoon illustration, or obvious comedy.

Humor should occur because **nothing about the buffalo is treated as humorous**.

---

# 8. Photography

### Primary aesthetic

Direct flash + deep blacks + documentary framing.

Photographs should feel discovered rather than produced for advertising.

### Environment

Buenos Aires nightlife should appear through texture:

Chacarita streets, concrete, shutters, tiled interiors, club corridors, equipment cases, venue entrances, taxis, fluorescent light, posters, electrical infrastructure, empty rooms and late-night environments.

### Composition

Hard crops are encouraged.

The mascot may partially leave the frame.

Foreground obstruction is acceptable.

Imperfection is preferable to polished lifestyle photography.

### Buenos Aires rule

Represent Buenos Aires through **specificity, not symbolism**.

Do not default to tango, flags, mate, fútbol, landmarks or obvious national motifs.

---

# 9. Graphic Language

A core DJ Bufalo composition normally contains:

**1 dominant statement + 1 image/object + 1 metadata layer + 1 unexpected detail**

Example:

**DJ BUFALO**
buffalo portrait
`04:17 / CHACARITA / BUF-019`
small violet handwritten observation

This pattern is reusable without making every asset identical.

### Supporting elements

Thin rules, catalog codes, coordinates, track timestamps, mono captions, tiny category labels, administrative language, small arrows, restrained outlined icons, archival-looking photographs and occasional handwritten violet interventions.

# 10. Layout System

## Desktop baseline

| Property             |   Specification |
| -------------------- | --------------: |
| Reference canvas     |         1440 px |
| Content width        |    1060–1120 px |
| Minimum outer margin |           72 px |
| Grid                 |      12 columns |
| Gutter               |           24 px |
| Section spacing      |          120 px |
| Major module spacing |           64 px |
| Component spacing    | 24 / 32 / 48 px |

### Hero

**5 columns:** copy
**7 columns:** imagery

### Editorial sections

**4 columns:** secondary imagery
**5 columns:** primary content
**3 columns:** annotations / secondary metadata

### Alignment

Most elements obey the grid.

Only three categories may intentionally break it:

**Buffalo photography / violet handwriting / archival fragments**

The exception creates tension because the rest of the system is controlled.

---

# 11. Spacing System

Use a base spacing rhythm built around:

`8 / 16 / 24 / 32 / 48 / 64 / 96 / 120`

Avoid arbitrary gaps.

Large negative space is part of the identity and should not automatically be interpreted as “empty space to fill.”

---

# 12. Iconography

Icons should be functional and minimal.

Preferred style:

Thin monoline, geometric, monochrome.

Suitable subjects include play, location, sound, clock, globe, contact, technical equipment and directional arrows.

The buffalo icon can be filled rather than outlined to differentiate it from utility icons.

Avoid decorative icon packs and rounded corporate-app iconography.

---

# 13. Voice & Language

### Tone

**Deadpan / Cultured / Nocturnal**

Copy should sound confident without hype.

### Preferred language behavior

Spanish is culturally primary.

English can be used selectively, particularly for memorable recurring statements or international-facing communication.

The two languages can coexist without translating every line.

### Approved voice examples

**Nunca apura la bajada.**

**Never rushes the drop.**

**Cero firuletes.**

**No requests after 4am.**

**Música para gente trasnochera.**

**La precisión es una forma de respetar al que baila.**

**La mirada clavada.**

The best copy sounds like an observation, rule, or fact—not an advertisement.

---

# 14. Copy Rules

Avoid:

“Epic night.”
“Unforgettable experience.”
“Get ready.”
“Party like never before.”
“Feel the energy.”
“World-class DJ.”
“Electronic music journey.”

That language destroys the specificity of the brand.

Prefer statements that sound particular to Bufalo:

**Tres horas. Sin apuro.**

**Siempre cierra.**

**04:17 todavía es temprano.**

**La pista también es nuestra.**

**No hace falta explicar al animal.**

---

# 15. Website Baseline

The current website direction becomes the **master digital reference**.

Primary sections:

**Hero → Biography → Specs → Selected Sets → Rider → Manzia Contact → Footer**

The site should remain dark, spacious and editorial.

Interactive behavior should stay restrained.

No buffalo cursor, bouncing horns, novelty loading screen or excessive club animation.

Movement should support atmosphere and hierarchy—not perform the joke.

---

# 16. Social System

Instagram should alternate among:

**Artist / character photography, event communication, statements, music/release material, archival Buenos Aires imagery, set documentation, merch and occasional rider/world-building material.**

The feed should not require every square to look like the same template.

Consistency comes from:

Palette, typography, photographic treatment, metadata, voice and recurring Bufalo behavior.

---

# 17. Event Poster System

Posters should prioritize information in this order:

**Artist → Event idea → Place → Date/time → promoter/administration**

DJ BUFALO should usually remain visually dominant.

The mascot may be dominant or absent depending on campaign concept.

Every poster does **not** require buffalo photography.

This prevents the character from becoming repetitive.

---

# 18. Record Artwork

Release artwork can be more experimental than promotional material, but must preserve at least two system signals.

Examples:

Typography + metadata
Photography + palette
Buffalo + layout logic
Amber + mono catalog language

Do not force the full identity onto every record cover.

Records should feel related, not templated.

---

# 19. Merchandise

Merch should feel like something someone would wear **without needing to explain the joke**.

Preferred:

Small chest marks, oversized back typography, location references, phrases, catalog information, buffalo silhouette and limited photographic applications.

Avoid mascot merch that feels like fan-club novelty products.

Black garments are the baseline, with Bone print and selective Amber.

Violet should be extremely limited.

---

# 20. Quality Filter

Before approving any DJ Bufalo asset, ask:

**Does this feel like underground culture or nightlife marketing?**

**Does the buffalo feel inevitable or gimmicky?**

**Is Buenos Aires present through specificity rather than cliché?**

**Is there enough restraint?**

**Could this exist without amber or the mascot and still feel like the same brand?**

**Does the humor reward attention instead of demanding attention?**

If the answer breaks the system, the asset goes back into **Recovery Mode**.
